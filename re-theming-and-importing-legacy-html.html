Re-theming and Importing Legacy HTML

How theme preview/apply and unmanaged-page imports work together when adopting an existing static site.

#blog#workflow#migration

Many static sites already have years of pages in place before anyone asks for better editing tools. WYSiteIWYG is designed for that reality. Instead of forcing a full rebuild first, it lets administrators preview a theme, import unmanaged HTML, and gradually convert old pages into editable blocks.

The theme workflow is intentionally cautious. Preview lets you inspect the homepage in another visual language before you commit. Apply then rewrites the active templates and managed pages while preserving shared structures such as the menu.

Import only what you need

The unmanaged-file scanner detects HTML outside /edit/ and offers standard, bulk, or advanced import. Standard import wraps the main content in one block. Advanced placement lets you choose exactly which child elements should become separate editable regions.

That makes WYSiteIWYG a migration tool as much as an editor. Teams can keep publishing while they modernize the site in stages rather than freezing everything for a wholesale platform change.
