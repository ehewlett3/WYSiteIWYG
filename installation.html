Installation

A typical deployment workflow for a new WYSiteIWYG site.

This page outlines the practical sequence most administrators will follow on a normal PHP-capable host.

Recommended first-run checklist

  1. Upload the site files so the public HTML pages sit at the site root and the editor lives at /edit/.
  2. Confirm the host can run PHP sessions and that the site files are writable by the web server process wherever you expect edits to be saved.
  3. Visit /edit/ and create the first administrator account.
  4. Open the dashboard, preview the available themes, and apply the one you want as the starting point.
  5. Edit the shared menu so it reflects the site structure you actually want to publish.
  6. Create a few starter pages or import unmanaged HTML files that already exist on the server.

The application is designed so those tasks can all be completed without leaving the browser once the files are in place.

What to prepare before installation

Requirement Why it matters
HTTPS enabled Protects session cookies and editor logins in transit.
PHP with sessions Required for authentication, CSRF protection, and editor routing.
Writable HTML files Edits are saved directly back into the published files on disk.
Writable edit/storage/ Needed for live user data and configuration that should not be committed to Git.
Version-controlled source copy Recommended so theme rewrites and content changes can be reviewed and backed up cleanly.

For a fresh rollout, it is usually easiest to start with the active default theme, confirm editing works, and only then experiment with alternate theme families.

After the editor is live

Set the theme

Use the theme preview cards to test the homepage, then apply the selected theme to rewrite the public pages and templates.

Import existing pages

If the server already has unmanaged HTML files, bring them into WYSiteIWYG from the dashboard instead of rebuilding them from scratch.

Create editors

Add separate editor accounts once the first administrator has confirmed the installation is stable.
