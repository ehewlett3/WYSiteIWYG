Welcome to WYSiteIWYG

An overview of the editing model, theme system, and tag-driven publishing workflow.

#blog#launch

WYSiteIWYG is built around a simple promise: the published HTML file should still be the real site, not a generated export from some separate authoring database. The editor fits around that idea instead of replacing it.

Pages, posts, menus, and themes all work from the filesystem outward. Editors can sign in, open the exact block they need, and save directly back into the live page without breaking the static deployment model.

Tag landing pages

Add hashtags such as #blog, #launch, #workflow, or #migration in the page-details view and WYSiteIWYG rebuilds the matching landing pages automatically with links and excerpts.
