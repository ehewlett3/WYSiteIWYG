✦ Theme Character

A more generic parish-theme base

The intention here is not to freeze one parish snapshot forever. It is to preserve the broad visual sensibility while keeping the actual content, clergy details, schedules, and messaging easy to replace.

Reverent masthead

A strong header gives the site immediate church identity without overwhelming the content.

Layered sidebars

Schedules, location details, support information, and clergy contact can live beside the main editorial stream.

Formal typography

The palette and type choices aim for dignity rather than startup minimalism.

Flexible content blocks

News, teaching, service times, visitor guidance, and parish support can all use the same theme scaffold.
