Themes and Imports

How theme previews, page rewrites, unmanaged HTML imports, and advanced placement work together.

Theme preview and apply

Theme cards in the dashboard let you preview the homepage in another theme before you commit to it. Applying a theme rewrites the public pages and active template scaffolds to match the selected design.

  • Preview is a temporary overlay so you can inspect the new presentation before rewriting files.
  • Apply rewrites the active public stylesheet, page templates, and discovered managed pages.
  • The menu is preserved and normalized so the shared navigation remains intact across themes.

Importing unmanaged HTML files

The dashboard now scans for HTML files outside /edit/ that do not yet contain WYSiteIWYG markers. Those files can be imported individually or all at once.

Mode Result
Standard import Uses the first <main> element if present, otherwise the <body>, and places that content into one editable Page Content block.
Bulk import Imports every unmanaged file with confirmation, useful when adopting an existing small static site.
Advanced import Lets you choose a container XPath and optional child-element XPaths so imported sections become multiple ordered editable blocks.

Advanced placement workflow

When a legacy page has several major sections, the advanced import tool can split them into multiple editable blocks during import.

  1. Choose the unmanaged HTML file from the dashboard.
  2. Set the import container XPath if you want something narrower than the default <main> or <body>.
  3. Enter one XPath per line for the direct child elements that should become their own Page Content blocks.
  4. Import the page so the current theme is applied and the chosen content regions become editable in place.

This gives administrators a way to migrate an older site gradually instead of hand-rebuilding every page before the editor becomes useful.
